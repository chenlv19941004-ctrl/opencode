# 禁止事项

| 禁用项                       | 替代方案             |
|---------------------------|------------------|
| `lodash`                  | `lodash-es`      |
| `useCallback`             | 不使用              |
| `Ant Design`              | `Tea Component`  |
| `git commit` / `git push` | 由用户手动执行          |
| `class 组件`                | 函数式组件            |
| 内联 return 语句              | 使用大括号包裹          |
| 组件内编写业务逻辑                 | 通过 props/回调暴露给外部 |
| 禁止执行构建命令                  | 不需要执行构建          |
