# 通用 UI 交互规范

开发过程中，除了遵守各子仓的开发规范和代码约定之外，还需要遵循一些通用的 UI 交互规范，以保证整个系统的用户体验一致性和易用性。以下是一些主要的交互规范：

### 文本展示 交互规范

- 名字、描述等文本类内容展示，需要考虑到文本超长的情况时，需要显示...省略号，并且鼠标hover到文本上时，弹出小气泡显示完整内容，优先使用
  `EllipsisHover`组件实现这个交互

### 按钮交互规范

- 可点击的按钮鼠标hover时，鼠标指针需要变成小手，提示用户该元素是可点击的
- 按钮的状态需要有明确的视觉反馈，例如：正常、悬浮、点击、禁用等状态需要有不同的样式表现，以便用户能够清晰地识别按钮的状态和可用性

## 表格交互规范

- 表格的数据总条数小于等于当前分页最小页码时，不展示分页器
- 表格在切换排序字段时，需要把分页页码重置为第1页
