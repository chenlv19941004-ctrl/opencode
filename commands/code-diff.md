# Code Diff 代码变动统计

> 统计指定仓库指定分支相对于 release 分支的代码变动行数

---

## 使用方法

```bash
/code-diff <仓库名> <分支名>
```

**参数说明**：

| 参数 | 必填 | 说明 |
|------|------|------|
| 仓库名 | 是 | 仓库别名或完整路径 |
| 分支名 | 是 | 要对比的分支名称 |

**仓库别名映射**：

| 别名 | 完整路径 |
|------|----------|
| dbh | src/pages/home |
| dbi | src/pages/intelligence |
| dbg | src/pages/globalpedia |
| dbu | src/pages/user-center |

**示例**：

```bash
# 使用别名
/code-diff dbi feat-rspack-chenl
/code-diff dbh feature/new-login

# 使用完整路径
/code-diff src/pages/home feature/new-login
```

---

## 执行流程

### 步骤 1：解析参数

1. 解析仓库名参数：
   - 如果是别名（dbh/dbi/dbg/dbu），转换为对应完整路径
   - 如果不是别名，直接使用传入的路径

2. 构建绝对路径：
   - 基础路径为当前项目根目录
   - 将相对路径转换为绝对路径

3. 验证仓库和分支：
   ```bash
   git -C <绝对路径> rev-parse --git-dir  # 验证是否为 git 仓库
   git -C <绝对路径> rev-parse --verify <分支名>
   ```

### 步骤 2：获取当前 Git 用户

```bash
git config user.name
git config user.email
```

保存用户信息用于后续过滤。

### 步骤 3：获取当前用户的 Commits

获取指定分支上当前用户的 commit 列表（相对于 release 分支）：

```bash
# 获取当前用户在指定分支上相对于 release 的 commits
git -C <绝对路径> log release..<分支名> --author="<user.email>" --pretty=format:"%H"
```

### 步骤 4：统计代码变动行数

```bash
# 统计每个 commit 的变动行数，然后汇总
git -C <绝对路径> log release..<分支名> --author="<user.email>" --numstat --pretty=format:""
```

输出格式：`新增行数\t删除行数\t文件路径`

解析并累加：
- **新增行数**：所有新增行的总和
- **删除行数**：所有删除行的总和

### 步骤 5：输出统计结果

以文本格式输出统计结果：

```
==================================================
  Code Diff 统计报告
==================================================

仓库路径: <仓库路径>
对比分支: <分支名> vs release
统计用户: <user.name> (<user.email>)
统计时间: YYYY-MM-DD HH:MM:SS

--------------------------------------------------
  Commits 统计
--------------------------------------------------
  当前用户 commits: X 个
  总 commits: Y 个

--------------------------------------------------
  代码变动统计
--------------------------------------------------
  新增行数: XXX 行
  删除行数: XXX 行
  净变动:   XXX 行

--------------------------------------------------
  文件变动统计
--------------------------------------------------
  变动文件: X 个

  变动文件列表:
  - path/to/file1.tsx (+XX, -XX)
  - path/to/file2.scss (+XX, -XX)
  ...

==================================================
```

---

## 注意事项

1. **分支切换**：执行过程中不需要切换分支，使用 `git diff release..<分支名>` 进行对比
2. **用户过滤**：只统计当前 git 用户的 commit，不统计其他人的
3. **文件类型**：统计所有文件类型，不排除任何文件
4. **统计范围**：
   - 新增行：代码中 `+` 开头的行（不含 diff 元信息）
   - 删除行：代码中 `-` 开头的行（不含 diff 元信息）
5. **基准分支**：始终对比 release 分支

---

## 错误处理

| 错误情况 | 处理方式 |
|----------|----------|
| 仓库路径不存在 | 提示 "仓库路径不存在：<路径>" |
| 不是 git 仓库 | 提示 "不是有效的 git 仓库：<路径>" |
| 分支不存在 | 提示 "分支不存在：<分支名>" |
| release 分支不存在 | 提示 "基准分支 release 不存在，请先拉取" |
| 无变动 | 输出 "当前用户在 <分支名> 分支无代码变动" |
